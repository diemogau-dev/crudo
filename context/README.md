# Carpeta de contexto

Contexto vivo del proyecto. Actualizar estos archivos a medida que cambien las decisiones — no duplicar información en otros lugares del repo.

- `general/contexto-maestro-house-of-brands.md` — contexto del proyecto madre (constructora + house of brands). CRUDO es la primera marca del portfolio.
- `crudo/brief-proyecto-web.md` — brief completo de la web de CRUDO (estrategia, estructura, copy, reglas).
- `crudo/manual-de-marca.html` — **Manual de Marca oficial (Edición 01)**. Abrirlo en el navegador. Manda sobre cualquier otro archivo en logo, paleta, tipografía, imagen y tono; usarlo para todo diseño nuevo.
- `crudo/manual-marca.md` — resumen operativo de identidad de marca (paleta, tipografía, tono, CTAs, WhatsApp). Si choca con el manual oficial, manda el manual.
- `crudo/decisiones-y-preguntas.md` — registro vivo de decisiones tomadas y preguntas abiertas a lo largo del proyecto.
